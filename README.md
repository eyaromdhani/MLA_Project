# MLA_Project
Breast Cancer Diagnosis with an Artificial Neural Network
State of the Art

Breast cancer is a major cause of death among women. Detecting and treating it early greatly improves outcomes, but doctors can make mistakes. A computer-based tool can support them by indicating whether a tumor is benign or malignant.

In this project, we train an Artificial Neural Network (ANN) on measurements extracted from images of cell nuclei, in order to classify tumors as malignant or benign with high accuracy.


Business Objectives (what we want for patients)

BO1: A cancer that goes undetected can be deadly, so this is the top priority.
BO2: Help make fair and reliable screening decisions. 

Data Science Objectives (what we want from the model)

DO1: The model should catch at least 95% of malignant tumors out of every 100 real cancers.
DO2: Find the best model settings using the Taguchi method.
